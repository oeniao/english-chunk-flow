# Annotation contract

The current assistant produces the annotations using its language understanding. No extra text-model key is required for this mode. Do not represent it as an installed automatic parser.

JSON:

```json
{
  "title": "A useful meeting",
  "subtitle": "一次有用的会议",
  "locale": "zh-CN",
  "source_type": "text",
  "source_url": "",
  "sentences": [
    {"text": "The meeting is useful.", "translation": "这场会议很有用。", "parts": [
      {"role":"s","en":"The meeting","zh":"这场会议"},
      {"role":"v","en":"is","zh":"是"},
      {"role":"b","en":"useful.","zh":"有用的"}
    ]}
  ]
}
```

`locale`: zh-CN, ja, ko, ar, es, pt, de, ru or en. `zh` is the legacy field name for the selected-language meaning, even when not Chinese. Roles: s subject, v predicate, o object, b predicative complement, a modifier, c clause, k core chunk, e object complement. Translate role labels separately; the CLI/player localizes them.

Parents use `children`. By default the parent's `en` is its own spoken head, followed by children, e.g. object “a plan” with child “that will help commuters”. Use `containerOnly:true` for a wrapper whose `en` describes the complete child span and is NOT spoken a second time. Such wrapper text must match its children's English exactly. `relation` optionally explains attachment in the selected language. IDs, leaves and timings are generated by CLI, never invent them.

Concatenated spoken leaves must equal the sentence, and all sentence text must equal source.txt under whitespace-only normalization. Preserve punctuation, capitalization, numbers and contractions. No silent paraphrase in imported text. Source extraction/cleanup must be inspected before annotation.

Long clauses can expose local s/v/o/b; long single phrases can use k children within the role parent. Stop when splitting no longer helps. Main predicate and complement must remain clear. A subject need not be at the start; subordinate subjects belong inside the subordinate parent. Nonfinite or broken spoken clauses may have no finite predicate; do not invent missing words.

Suggested level/duration: use a stable familiar topic, mostly known vocabulary, with necessary longer sentences for structure practice. Estimate 130–150 words/min but use actual voice duration after build; a five-minute request should be close to five minutes, not called exactly five minutes when it is not.
